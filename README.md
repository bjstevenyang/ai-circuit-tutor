# AI Circuit Tutor

一个面向 12–16 岁学生的面包板电路实验室：亲手搭建、查看真实连接、运行有限仿真，再通过逐级提示修复错误。

第一课使用一个理想 4.5 V 电池、一个电阻和一颗红色 LED。课程提示是经过审阅的确定性内容，当前未接入生成式 AI。

第一次使用请阅读 [使用说明书](docs/USER_GUIDE.md)，包含完整孔位接线示例、删除操作、提示说明和常见问题。

## 本地运行

需要 Node.js 22.12 或更新版本，建议 Node.js 24。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。

```sh
npm run typecheck
npm run lint
npm test
npx playwright install chromium firefox webkit
npm run test:e2e
npm run build
npm run preview
```

依赖锁定在 `package-lock.json`。CI 执行类型、静态检查、单元／交互测试、生产构建和三种浏览器引擎的流程测试。

## 操作

1. 选择电阻或 LED，指向孔位查看引脚预览，点击放置；也可使用“精确放置”输入锚点和方向。
2. 选择连线工具，依次点击两个端点；也可填写“导线起点”和“导线终点”。
3. 选择孔位查看导电网络；使用连接观察器可直接输入孔位名称。
4. 点击“运行电路”。诊断出现后，按需揭开提示；任何修改后需要重新运行。
5. 选中元件可移动、旋转或改变电阻值；选中导线可改变颜色和折线路径。删除时点击工作台上方的“删除”，或按 Delete／退格键；输入框内的按键只编辑文字。误删可撤销。

孔位使用 `a1`–`j30`；电池为 `battery:+`、`battery:-`；电源轨示例为 `top+:1`、`bottom-:30`。SVG 孔位支持 Tab 聚焦、方向键移动和 Enter 选择；精确操作表单可用键盘完成。

作品只自动保存在当前浏览器中，刷新可恢复；保存失败会显示并保留内存作品。损坏或未知版本的存档不会被自动覆盖。编辑历史最多 50 步，仅保留在当前会话。多标签同时编辑采用最后成功保存的文档。

## 支持范围

- 一块 30 行面包板：每行 a–e、f–j 分别内部相连，中央沟槽隔离；四条电源轨各自连续且独立。
- 一个电阻（100、330 或 1,000 Ω）、一个红色 LED，以及理想导线。
- 受支持串联回路的估算电流、LED 极性和课程限流检查；错误与不支持接法分别反馈。
- 桌面／笔记本鼠标、触控板及键盘。触摸编辑、账户、云同步和任意电路求解不属于当前范围。

LED 采用固定 2.0 V 正向压降，课程电流限制为 20 mA。忽略电源内阻、容差、温度、发热、泄漏、击穿和损坏。数值是教学近似，不用于预测真实器件安全性。完整约定见 [电路模型](docs/CIRCUIT_MODEL.md)。
