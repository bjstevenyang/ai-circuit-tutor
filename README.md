# AI Circuit Tutor

面向 12–16 岁学生的虚拟面包板实验室：根据电路图试验连接，观察真实导电网络，运行有限直流模型，通过逐级提示自行修复。

基线八类提供电阻、红色 LED、通断开关、常开按钮、电位器、有源蜂鸣器、二极管、光敏电阻，允许多个实例；支持元件拖动及拖动连线。电阻支持自定义数值，电池电压可调；LED 标注 A＋／K− 并按支路电流显示相对亮度；蜂鸣器音量可调，运行中可直接点击开关本体切换。当前提示为经过审阅的确定性内容，尚未接入生成式 AI，也没有目标电路图自动判题。

阶段2新增共阴 RGB、有限低侧 NPN、单电容线性 RC 和无源压电；实验电源增加互斥的教学方波模式。新元件说明、实际引脚、动态读数、三级提示及配置保存均在同一工作台。复杂混接会明确说明模型限制；不提供任意电路求解。验收状态见 [阶段2实施记录](docs/changes/STAGE-2-IMPLEMENTATION.md)。

电位器的 A／W／B 逐脚标注，选中可查看实际孔位、内部电阻段，以及 LED 调光和三脚分压接线说明。

第一次使用请看 [使用说明书](docs/USER_GUIDE.md)，含可直接照做的 LED、按钮和蜂鸣器孔位示例。

## 本地运行与检查

需要 Node.js ≥22.12，建议 24；依赖由 package-lock.json 锁定，本版没有增加依赖。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 http://127.0.0.1:5173 。

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e -- --project=chromium
```

按用户当前要求，本地和 CI 先只执行 Chromium（Chrome 引擎）浏览器测试。Playwright 保留其他引擎配置，后续经用户指示再启用。CI 结果须以实际运行状态为准。

## 操作

1. 选择元件时，右侧显示用途、引脚和接法说明；点击板上元件可查看实际引脚孔位。预览全部引脚后点击孔位放置；或用精确放置表单。
2. 抓住元件本体拖动，松手吸附；非法位置保留原位，Esc 取消。也可精确输入或点选移动。
3. 选择“连线”，点击两个端点，或按住起点拖到终点；也可填写导线表单。已有线选中后可拖动两端圆点改接，或用下方改接表单。交叉不连接。
4. 点击“运行电路”，按钮变为“停止运行”，并显示运行状态。运行中开关、按钮、阻值、电池电压、旋钮和光照会即时重新求解；改线／移动等编辑后须重新运行。
5. 运行中绿色开关直接点击切换；黄色圆钮按住接通、松开断开，本体也支持 Enter／Space 按住。黄色按钮拖动灰色外壳移动。选中对象后用工具栏“删除”或 Delete／退格键删除，文字输入不触发对象删除；误操作可撤销。
6. 查看诊断，按需揭开三级提示。蜂鸣器默认只显示视觉状态，主动启用后才播放声音，音量可调 0–100%。

“停止运行”清除实时读数、提示和光／声输出，释放临时按钮；接线、参数和开关位置保留。停止时开关本体点击仅选择，重新运行才恢复仿真。当前是按交互求解的直流模型，没有持续计时循环。

孔位 `a1`–`j30`，电池 `battery:+`／`battery:-`，电源轨如 `top+:1`／`bottom-:30`。孔位支持方向键和 Enter；完整操作也可不拖动完成。

## 范围与限制

- 一块 30 行面包板，每行 a–e 和 f–j 各自相连；四条电源轨独立连续。
- 固定位置的理想电池（1.5–9 V，默认 4.5 V），最多 24 个元件、120 根导线；LED／二极管／蜂鸣器合计最多 6 个。
- 支持小型直流串并联、带载分压和电阻网络；无法唯一确定的电流不猜测，例如理想 LED 直接并联共用一只电阻。
- LED 2.0 V、二极管 0.7 V 为固定压降；每颗 LED 的 20 mA 是课程约定。蜂鸣器、光敏电阻是明确的教学近似。
- 作品自动保存在本浏览器，兼容旧作品。刷新不恢复历史、结果、按钮按压和声音许可／音量；自定义电阻及电池电压会恢复，兼容旧版 4.5 V 作品。历史最多 50 步；多标签最后成功保存者覆盖。
- 未提供后端、云同步、账户、通用 SPICE、交流／瞬态、移动端编辑或真实器件安全预测。

## 阶段2性能检查

仅Chromium。生产性能测试构建独立写到临时目录，不进入正常发布包，也不读取学生作品；使用已有依赖。

```sh
npx vite build --config tests/performance/vite.config.ts
npm run test:performance -- --grep 'fixed B'
npm run test:performance -- --grep 'M-'
npm run test:performance -- --grep 'UI'
```

M-RC／M-PIEZO各需十个真实60秒会话。UI-RC还需每次恢复到模拟5秒，耗时较长。采样输出在`/tmp/ai-circuit-stage2-*.json`。目标机器M1／8GB；其他硬件只能提供补充结果。实际未验证项始终记录，不因测试文件存在就视为通过。
