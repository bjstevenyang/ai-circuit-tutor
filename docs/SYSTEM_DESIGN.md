# AI Circuit Tutor：系统设计

日期：2026-10-30。需求基线：[PRD](PRD.md)。电气规则：[CIRCUIT_MODEL](CIRCUIT_MODEL.md)。本轮已授权实现整个 MVP。

## 1. 总体结构

React、TypeScript 严格模式、Vite 和 SVG 单包静态前端；当前无需后端。React reducer 管理文档历史与运行状态，局部状态管理工具、输入和预览。

| Module | 职责 | 主要 Interface |
| --- | --- | --- |
| circuit | 板定义、引脚推导、导电网络、受支持拓扑识别、有限仿真与证据 | createEmptyDocument、getComponentPins、inspectConnectivity、analyzeCircuit |
| editor | 物理安装校验、纯编辑命令、SVG 表示、历史 | applyEdit、createHistory、commitDocument、undo、redo |
| tutor | 已审阅诊断文字与三级提示 | getDiagnosticCopy、nextHintLevel |
| storage | 浏览器存储获取、运行时文档校验、加载和保存 | loadWorkspace、saveWorkspace |
| app | 组合、用户操作、显式运行、提示请求和保存反馈 | React App |

circuit 不导入 React、DOM、SVG 或 storage。浏览器交互调用与测试相同的纯命令和分析 Interface；图形坐标不能成为电气身份。

## 2. 权威状态与数据

CircuitDocument 保存 schemaVersion、boardId、lessonId、元件和导线。元件包含稳定 ID、类型、参数、锚点和离散旋转；引脚位置从安装形态推导。导线包含稳定 ID、from/to 端点、颜色及折线路径。

BoardDefinition 共享孔位坐标和内部导电组，保证渲染与分析一致。每孔一个插入端；电池每端口一个导线端。导电网络由板内部连接及导线推导，器件保持为网络间支路。

保存不包含网络、数值结果、提示进度、预览、选择或历史。历史保存最多 50 份已提交文档快照，无事件溯源或通用可逆命令框架。

## 3. 编辑、分析和教学数据流

1. 指针或表单产生编辑命令；预览调用相同放置校验。
2. applyEdit 先校验完整候选状态，成功后原子返回新文档，失败返回解释并保留旧文档。
3. 成功操作提交一次历史并尝试保存；旧分析、提示层级和诊断选择失效。
4. 只有“运行”调用 analyzeCircuit；结果包含状态、可用数值、完成判断及诊断代码／对象引用。
5. tutor 将代码映射成课程文字；学生主动请求后展示下一层提示。

元件本体包围区域禁止相互重叠，导线跨越不参与本体碰撞。合法放置不意味着电气正确，不能把同一导电组上的双引脚当物理错误拒绝。

分析不得根据旧运行状态继续显示 LED 导通。多个诊断使用模型规定顺序；不确定原因不能描述为已证明的根因。具体修复由学生执行。

## 4. 保存与失败

单工作区使用 localStorage。加载进行结构、版本、引用、器件参数及物理约束校验。空存储创建空文档，合法存储恢复；不可读取、损坏或未知版本返回明确错误并暂停自动保存。

用户明确选择后可用当前内存作品替换无法读取的存档。写入失败保留文档和输入，显示未保存并提供重试。没有备份、迁移框架、跨设备同步或多标签合并，最后成功写入者覆盖。

浏览器存储获取本身可能抛异常，因此访问和读写分别捕获。存档文本不得作为 HTML 执行，外部服务或密钥不进入前端。

## 5. 可访问性与验证

SVG 孔位使用稳定可访问名称、方向键导航及 Enter 选择；所有关键操作还有表单／按钮路径。放置不依赖拖动；焦点、选中、网络和错误不能只靠颜色区分。复杂画布可单独滚动和放大。

模型正确性由纯模块测试验证；SVG 坐标转换、事件和键盘操作由浏览器测试验证。类型检查独立于构建工具执行。测试映射与人工发布门槛见 [TEST_PLAN](TEST_PLAN.md)。

未来 AI 可消费结构化诊断，但不允许其改变确定性电气结论；真正接入前另行设计服务端凭据、隐私、内容质量及故障回退。
