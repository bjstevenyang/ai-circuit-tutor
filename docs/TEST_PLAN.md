## 2. 执行命令

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

首次浏览器测试前执行 `npx playwright install chromium firefox webkit`。测试使用独立浏览器上下文及本地测试存储，不读取学生个人作品。纯模块测试不需要浏览器或外部网络。

浏览器流程覆盖：搭建成功、观察连接、刷新恢复；反向 LED → 请求三层提示 → 删除并重新放置 → 成功；指针预览与非法占用；撤销／重做；纯键盘搭建；存储失败反馈。三种引擎项目为 Chromium、Firefox、WebKit，不能把 WebKit 自动化等同于实际 Safari 人工验证。
