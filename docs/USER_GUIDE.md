# AI Circuit Tutor 使用说明书

适用版本：阶段2工作台 · 更新日期：2026-11-04

本应用是一间虚拟电路实验室，适合第一次接触面包板的学生。现在可以用十二类元件在明确范围内试验电路；新增RGB／NPN／RC／压电见文末阶段2实验，以下先介绍基线八类，通过“搭建 → 观察连接 → 运行 → 根据提示修复”。

如果页面已经打开，直接从“认识界面”开始。需要启动应用时，参见文末“本地启动”。

## 1. 认识界面

| 区域 | 可以做什么 |
| --- | --- |
| 左侧「元件盒」 | 选择八类元件；允许同类多个实例 |
| 左侧「精确放置」 | 输入元件、锚点孔位和方向，准确安装引脚 |
| 左侧「连接导线」 | 输入起点、终点，选择导线颜色和折线路径 |
| 中间工作台 | 查看面包板、电池、元件和导线；选择孔位或对象 |
| 工作台上方工具栏 | 查看连接、连线、撤销、重做、重置、删除和运行电路 |
| 工作台下方 | 查看选中对象的信息，移动／旋转元件、修改阻值或导线外观；未选中对象时显示连接观察器 |
| 右侧「一起想一想」 | 查看运行结果、诊断和逐级提示 |
| 页面顶部保存状态 | 确认作品是否已经保存到当前浏览器 |

窗口较窄时，部分区域会移到下方。画布可以单独滚动；用画布上方的 `+ / −` 将其放大或缩回，范围为 100%–175%。

### 不认识元件时先看哪里

点击左侧「元件盒」中的任一元件，右侧会出现「认识元件」说明，介绍它是什么、引脚怎么认、怎么接入电路，并给出示例接法和可尝试的操作。八类元件都有说明，不需要先放到板上或运行。

- 点击板上已放置的元件，还能查看它每个引脚对应的实际孔位；旋转或移动后会同步更新。
- 点击「常见错误与模型说明」可以展开阅读。例如按钮会解释 1／2、3／4 两组连接；电位器会解释 A／W／B 的作用。
- 用 Tab 聚焦元件盒或板上元件，再按 Enter，也能查看说明；不需要悬停或拖动。
- 纯查看说明不会改变作品、撤销历史、运行结果或已揭开的提示。运行中绿色开关点击切换，黄色圆钮按住接通；只想阅读，可点击元件盒或按钮的灰色外壳。示例不会替你接线。

元件盒点击后仍处于放置模式，接着点击孔位会放置元件；只想阅读时，读完可切回「查看连接」。

## 2. 先看懂面包板

### 孔位名称

中央孔位用字母加数字表示，例如 `a6`、`b7`、`c12`。本板的编号 1–30 横向排列，字母 a–j 纵向排列。

| 位置 | 输入示例 |
| --- | --- |
| 中央孔位 | `a1` 至 `j30` |
| 电池正极／负极 | `battery:+` ／ `battery:-` |
| 上方正标记轨／负标记轨 | `top+:1` ／ `top-:1` |
| 下方正标记轨／负标记轨 | `bottom+:1` ／ `bottom-:1` |

电源轨冒号后的编号也是 1–30。输入时保留英文冒号 `:` 和半角加减号。

### 哪些孔内部相连

- 同一编号的 a–e 五个孔内部相连，例如 `a6`、`b6`、`c6`、`d6`、`e6`。
- 同一编号的 f–j 是另一组，例如 `f6` 至 `j6`。
- 中央沟槽隔开两组：`e6` 与 `f6` 不会自动相连。
- 相邻编号不自动相连：`a6` 与 `a7` 需要导线或元件连接。
- 四条电源轨各自连续，但彼此独立，也不与中央孔位自动相连。

**电源轨的 `+ / −` 是标记，不会自动供电。必须把电池正负极分别接到所用的两条轨道。** 导线颜色也只是帮助辨认，不决定正负极。

每个孔或电池端口只能插入一个端点。如果元件已经插在 `b6`，需要连接它时可使用同组的其他空孔，例如 `a6`。

### 查看实际连接

1. 点击工具栏「查看连接」。
2. 点击一个孔，观察哪些孔被一起高亮。
3. 展开「查看相连的孔位／端口」，阅读网络中的具体成员。

也可以在工作台下方「连接观察器」输入孔位名称，再点击「查看」。如果当前显示元件属性，先点击一个孔切换回来。

高亮表示通过内部导体、导线和当前闭合触点直接相连的网络，不会穿过非零电阻、LED 或二极管。它不表示这组孔已经通电。

## 3. 第一次搭建：让 LED 亮起来

本例使用电源轨，适合练习完整的电池接线。从空白工作台开始；如果已有想保留的作品，不要执行重置。点击「重置工作台」会清空当前作品并自动保存，误操作可立即撤销，刷新后无法恢复撤销历史。

### 第一步：放置两个元件

在左侧「精确放置」中，按下表逐个选择并点击「放置元件」。电阻默认是 330 Ω，本例电池使用 4.5 V。

| 元件 | 锚点孔位 | 方向 | 预期引脚 |
| --- | --- | --- | --- |
| 电阻（330 Ω） | `c9` | 向右 → | `c9 → c12` |
| 红色 LED | `b6` | 向右 → | `b6（A）→ b7（K）` |

锚点是元件的第一只引脚。LED 的第一只引脚是 A＋（阳极），朝向电源正极方向；另一只为 K−（阴极），朝向负极。图上 K 侧有平边和方形脚标记。旋转后文字与引脚对应关系不变，选中后还能在下方查看具体孔位。正负符号表示器件极性，不代表已经供电；LED 支路仍需串联限流电阻。

### 第二步：添加五根导线

在左侧「连接导线」中，每填完一对起点和终点，就点击一次「添加导线」。导线颜色和折线路径可自行选择，不影响连接。

| 顺序 | 导线起点 | 导线终点 | 用途 |
| --- | --- | --- | --- |
| 1 | `battery:+` | `top+:1` | 电池正极接上方正标记轨 |
| 2 | `battery:-` | `top-:1` | 电池负极接上方负标记轨 |
| 3 | `top+:6` | `a6` | 正标记轨接到 LED 的 A 极所在组 |
| 4 | `d7` | `d9` | LED 的 K 极所在组接到电阻第一端所在组 |
| 5 | `a12` | `top-:12` | 电阻另一端所在组接回负标记轨 |

为什么导线没有直接接在 LED 或电阻的引脚孔？因为同编号 a–e 内部相连：`a6` 与 `b6` 相连，`d7` 与 `b7` 相连，`d9` 与 `c9` 相连，`a12` 与 `c12` 相连。

完整路径是：

```text
电池正极 → 上方正标记轨 → LED 的 A 极 → K 极
        → 电阻 → 上方负标记轨 → 电池负极
```

### 第三步：运行和确认

点击工具栏「运行电路」。按上述孔位和默认阻值搭建时，应当看到：

- LED 点亮。
- 估算电池总电流约为 **7.58 mA**。
- 右侧显示「亮起来了！」及「电路检测通过」。

本例成功时 LED 正向导通且未超过单颗 20 mA 的课程限制。电阻可在 LED 任意一侧。自由实验的成功卡片表示至少一个 LED／蜂鸣器工作且当前没有诊断，不代表已经匹配某张目标电路图。当前还不能导入电路图或按目标图自动判题。

**首次搭建及改线后点击「运行电路」。** 已运行时，开关、按钮、阻值、旋钮和模拟光照变化会即时重新计算；移动、放置、删除、接线、撤销／重做会清除结果，需再运行。刷新恢复后也需要重新运行。

## 4. 放置、移动与旋转

### 用鼠标放置

1. 在「元件盒」选择需要的元件。
2. 指向孔位，查看全部引脚的预览；方向可在「精确放置」中调整。
3. 确认位置后点击孔位放置。不需要按住拖动。

当前电阻的两引脚相隔三个孔距，LED 相隔一个孔距。引脚不能任意拉伸，也不能以电源轨孔为安装锚点。

### 修改已放置的元件

先点击元件本体，在画布下方使用对应操作：

| 操作 | 方法 |
| --- | --- |
| 拖动移动 | 按住元件本体拖到新位置，查看全部引脚；松开提交，Esc 取消。非法位置保留原位，一次成功拖动可一步撤销 |
| 精确移动 | 在「新锚点」输入孔位，点击「移动元件」 |
| 点选移动 | 点击「点选移动」，指向新孔位查看预览，再点击确认 |
| 旋转 | 点击「旋转 90°」；锚点保持不变，其余引脚随封装旋转 |
| 修改阻值 | 选中电阻，在预设中选择常用值，或在「电阻阻值」输入 10–1,000,000 Ω 后点击「应用电阻阻值」 |

移动或旋转不会把原来孔位上的导线一起移动。修改后请重新检查接线。

如果提示引脚越界、孔位已占用或元件本体重叠，这次修改不会生效。更换锚点或方向后重试。两只引脚插在同一个内部连接组可能被允许，但电气上会把元件旁路，运行时会出现诊断。

## 5. 连线、选中与删除

### 用鼠标连线

1. 点击工具栏「连线」。
2. 点击起点孔位或电池端口。
3. 点击另一个空闲端点，完成一根导线。

也可以**按住起点孔位或电池端口，拖到目标孔位，再松开**。拖动中会预览折线路径和端点是否合法；松开才添加一根导线。占用端点、原地连接或落在空白处不会添加；拖动时按 Esc 可取消。颜色和折线路径沿用左侧当前设置。

工具栏下方会显示当前起点。想取消尚未完成的点选连线，切换到「查看连接」。孔位密集时，可以改用左侧起点／终点输入框。

导线只有两个端点建立连接。导线交叉、折弯或经过其他孔位，不会在途中自动接通。

### 修改导线

点击导线的线段，画布下方会显示它的起点和终点。可调整颜色，或点击「切换折线路径」。

**修改已有导线的连接孔：**

1. 点击导线线段选中它，两端会出现圆形手柄。
2. 按住要修改的一端，拖到新的空闲孔位或电池端口。
3. 查看预览后松手；另一端、颜色和折线路径保持不变。

拖到占用孔位、空白处或另一端所在的同一个孔会保留原连接；拖动时按 Esc 可取消。改接到原孔位没有变化；成功改接可一步撤销，并需要重新运行。

不方便拖动时，在画布下方选择「改接端点」（起点／终点），填写「新接点」，点击「修改接点」。也可让端点手柄获得键盘焦点，按 Enter 跳到该输入框。

### 删除元件或导线

1. 点击元件本体或导线线段，选中对象。
2. 点击上方工具栏「删除」，或者按 **Delete／Backspace（退格键）**。

没有选中对象时，「删除」按钮为灰色。只点击孔位是在观察网络，不是在选中元件；请点击元件本体。

输入框中的 Delete／退格键只编辑文字，不删除对象。删除元件后，原有导线仍接在原来的孔位，需要时单独删除。

误删或操作不合适时，可点击工具栏「撤销」，再用「重做」恢复。最多保留最近 50 次已完成编辑；刷新或重新打开页面后没有撤销历史。撤销后进行新的编辑，原来的重做历史会被清除。

## 6. 运行、停止与查看提示

点击工具栏「运行电路」后，状态显示「运行中」，按钮变为「停止运行」。此时绿色两脚开关直接点击切换通断；黄色四脚常开按钮直接按住圆钮接通、松开断开，LED／蜂鸣器和读数随之更新；参数变化也会即时重算。模型不会不断推进时间，而是在这些操作发生时计算直流结果。

点击「停止运行」后，状态变为「已停止」，LED 光效和声音停止，读数、诊断、提示及临时按钮按压清除。接线、元件参数、开关位置、撤销历史和声音设置保留。停止后点击开关本体只会选中；下方控件仍可预设通断。重新点击「运行电路」会按当前设置重新计算；若本会话已启用声音，正常工作的蜂鸣器也会恢复发声。

刷新页面或完成改线、移动、删除、撤销等编辑后会回到停止状态，需要再次运行。运行与停止本身不写入存档或增加撤销记录。

右侧会显示课程完成结果、电路诊断或当前模型的限制。出现问题时，可依次点击「揭开第一个线索」和「再给我一个线索」。

| 层级 | 提示作用 |
| --- | --- |
| 想一想 | 提醒相关的电路概念 |
| 看这里 | 指出需要观察的区域或引脚 |
| 试着修复 | 给出具体修复方向，由你亲手修改 |

每次只揭开一层，最多三层。多个诊断可点击切换；切换诊断或重新运行会从零层开始。编辑电路后旧诊断和提示失效。

| 提示／状态 | 含义与检查方法 |
| --- | --- |
| 回路还没有闭合 | 逐段检查电池正极、元件和负极之间的路径，特别检查电池是否连到电源轨 |
| 电池两极直接相连了 | 正负极之间出现只通过导线或面包板内部导体的直接连接；查找旁路线 |
| 这条路径缺少限流电阻 | 放入电阻还不够，电阻必须真正接入 LED 的串联路径 |
| 电流绕过了电阻 | 电阻两端在同一直接导通网络；检查同组孔或跨接其两端的导线 |
| LED 的两端被连在一起了 | LED 两端属于同一直接导通网络；检查引脚孔位和旁路线 |
| LED 的方向反了 | 已识别的回路中，LED 极性与电源相反；检查 A 朝向正极、K 朝向负极的关系 |
| 电流超过了课程限制 | 选中电阻，将 100 Ω 改成 330 或 1,000 Ω 后再运行 |
| 此接法超出当前模型范围 | 该接法无法得到唯一可靠的读数，或超出数量限制；例如并联 LED 共用一只电阻时，改为每个支路各串一个电阻 |
| 未计算 LED 状态 | 模型没有给出 LED 状态，不等于已经证明 LED 熄灭 |

### 两个小练习

先完成第 3 节示例，电池保持 4.5 V，再一次只改变一个条件：

- **练习电阻限流：**将电阻改为 100 Ω，重新运行，观察约 25 mA 的超限提示；改为 1,000 Ω 后应为约 2.50 mA，并满足课程限制。
- **练习 LED 极性：**删除示例中的 LED，再以锚点 `b7`、方向「向左 ←」放回，使 A 在 `b7`、K 在 `b6`。保持导线不变并运行，应出现接反诊断，模型电流为 0 mA。恢复时删除 LED，再按 `b6`、「向右 →」放置。

## 新元件怎么使用

选中元件本体后，在画布下方操作。在“运行中”使用这些控制会重新计算结果；停止时调整参数只保存设置。

| 元件 | 操作及注意事项 |
| --- | --- |
| 通断开关 | 运行中直接点击板上的开关本体切换；聚焦后可按 Enter／Space。未运行或停止时本体点击只选择，下方按钮仍能配置。拖动仅移动、不切换；状态会保存且可撤销 |
| 常开按钮（黄色圆钮） | 运行中直接按住板上的黄色圆钮接通，松开断开；也可聚焦元件后按住 Space／Enter，或使用下方控件。Esc、失焦或停止运行都会释放。拖动灰色外壳移动，按圆钮不会拖动元件；按压不保存 |
| 电位器 | 板上每个脚分别标出 A／W／B，W 是滑臂。选中后看“认清三个脚，再接线”，可查实际孔位、两段阻值及两种接法。旋转后按标记认脚；0% 时 W 接 A，100% 时 W 接 B |
| 有源蜂鸣器 | + 接较高电位、− 接较低电位；模型端电压为 3–5 V 时鸣响。先看视觉状态，需要声音时主动点击「启用蜂鸣器声音」；可随时关闭 |
| 二极管 | A 为阳极，带环端 K 为阴极；模型正向压降 0.7 V，反向截止 |
| 光敏电阻 | 调整「模拟光照」。越亮阻值越小；该百分比是模拟输入，不是实际光照单位 |

按钮四脚分两组：1 与 2 内部相连，3 与 4 内部相连；按下才连接两组。以 `e10`、向右安装时四脚是 `e10/e11/f10/f11`，适合跨沟槽；只接同组两脚无法用按钮控制通断。

**一个按钮实验：**从空板放电阻 `a1`、LED `c4`、按钮 `e8`，均向右。接 `battery:+ → b1`、`d5 → d8`、`j8 → battery:-`。运行后直接按住板上的黄色圆钮，LED 应亮；松开时熄灭。下方控件也可完成同样操作。把按钮换为开关 `a8` 时，最后一根线改为 `b10 → battery:-`，即可练习保持通断。

**一个蜂鸣器实验：**从空板放蜂鸣器 `a1`、向右，接 `battery:+ → b1`、`b3 → battery:-`，运行后应显示鸣响；声音仍需手动启用；可用「蜂鸣器音量」在 0–100% 调节，0% 静音。供电高于 5 V 会提示过压并停止鸣响。

多个 LED 逐颗显示状态，并随自身支路电流连续显示相对强弱；它是教学示意，不是真实亮度测量。无结果时显示未计算，超过 20 mA 显示封顶并保留超流提示。右侧是电池总电流，选中元件可看它的支路电流；20 mA 按每颗 LED 检查。电位器显示两段电阻中较大的支路电流，不是 W 端电流。瞬时按压不增加历史，滑块的每次数值变化可撤销。

### 电位器的 A、W、B 怎么接？

A、B 是电阻轨的两端，没有固定正负极；W 是随旋钮移动的滑臂。A–B 的总阻值不变，旋钮改变 A–W 和 W–B 两段。选中电位器后，画布下方会按实际位置列出三个脚的孔位和内部阻值；旋转或移动后同步更新。

- **LED 调光，先用两只脚：**电池＋ → 固定限流电阻 → A〔电位器〕W → A＋〔LED〕K− → 电池−，B 留空。4.5 V 入门实验保留 330 Ω 固定电阻，避免旋钮到零阻位置时没有限流。
- **三脚分压：**一种接法为 A 接正极方向、B 接负极方向、W 接负载，负载另一端回负极。接负载后输出会受负载影响，旋钮百分比不是输出电压百分比。

元件引脚已经占用了孔，不能再把导线插进同一个孔；应接到它同一五孔组里的其他空孔。A、W、B 不要落在同一导电组里，也不要在这些脚之间额外跨接导线。下方调光实验给出了可直接照做的孔位。

### 设置电压和自定义阻值

- 左侧电池卡下方可选 1.5、3、4.5、6、9 V 预设，也可在「电池电压」输入 1.5–9 V 之间的值，点击「应用电池电压」。
- 选中电阻，保留常用预设；也可在「电阻阻值」输入 10–1,000,000 Ω 的数值，再点击「应用电阻阻值」。输入单位为 Ω，支持小数和科学计数法，例如 1e3 表示 1,000 Ω。
- 输入时仍使用上一个已应用值。空白、非数字、负值、无穷大、十六进制和超范围值会提示错误；作品、运行结果和历史保持不变，输入可继续修正。
- 每次实际改变参数的合法应用产生一次可撤销编辑并自动保存；电路运行中立即重新计算。参数合法但 LED 电流超限时，会保留设置并给出诊断。

**调光实验：**电阻放 `a1`（默认 330 Ω），电位器放 `c4`（默认 10 kΩ），LED 放 `f10`，均向右。接 `battery:+ → b1`、`e5 → g10`、`g11 → battery:-`，电池用 4.5 V。电位器 A 接电阻，W 接 LED，B 不接。运行后调整旋钮，比较电流和 LED 相对亮度；固定 330 Ω 电阻负责限流。已有的电位器即可完成这个变阻实验。

蜂鸣器声音默认关闭，启用后音量默认 50%，可在 0–100% 调节，0% 静音。音量不改变电路电流，不进入撤销或存档；刷新后声音关闭、音量回到 50%。实际声音大小还受系统和扬声器设置影响。

黄色常开按钮像门铃，只有按住时接通；若希望点一下保持接通、再点一下断开，请使用绿色两脚通断开关。

## 7. 保存、恢复与作品保护

作品在每次完成编辑后自动保存到当前浏览器。查看页面顶部是否显示「已自动保存到此浏览器」。保存成功的作品可在刷新后恢复，旧版作品也会兼容读取；运行结果、撤销历史、按钮按压和声音许可／音量不会恢复；合法保存的电池电压、自定义阻值会恢复，v1／v2 旧作品按原有 4.5 V 兼容读取。

- 使用相同浏览器和相同访问地址继续操作。换浏览器、浏览器配置、主机地址或端口可能进入另一份存储。
- 目前只保留一个工作区，没有文件导出、备份、账户或跨设备同步。
- 不建议同时开多个标签编辑同一份作品，最后成功保存的内容会覆盖之前的内容。
- 清除浏览器网站数据可能丢失作品；未保存时不要依靠刷新解决问题。

| 保存状态 | 应对方法 |
| --- | --- |
| 未保存 | 当前作品仍在工作台内；检查浏览器存储权限或空间，再点击「重试保存」 |
| 原有作品尚未读取成功 | 自动保存已暂停，原存档不会自动被覆盖；当前仍可在内存中操作 |
| 以当前作品替换存档 | 只有决定用当前作品替换原存档时才点击，并确认提示；这不是恢复原作品的操作 |

## 8. 常见操作问题

| 问题 | 先检查什么 |
| --- | --- |
| 线路看似完整，但 LED 不亮 | 是否把电池两极接到了所用电源轨；是否点击运行；LED 极性和电阻是否正确 |
| 红色轨和蓝色轨都接了，还是不亮 | 轨道颜色不会供电；还要连接电池。上、下方同色轨也不自动相连 |
| 无法继续放置 | 检查占孔、越界、本体重叠；总元件最多 24 个，LED／二极管／蜂鸣器合计最多 6 个 |
| 导线无法插入元件引脚孔 | 该孔已被占用；使用同组内其他空孔 |
| 删除按钮是灰色 | 点击元件本体或导线线段；只选孔位不会选中对象 |
| 接线太密，难以辨认 | 放大并滚动画布；为导线选不同颜色／路径；用精确输入避免点错 |
| 修改后 LED 的亮光消失 | 旧结果已失效；点击「运行电路」重新判断 |
| 页面打不开 | 检查本地服务是否还在运行，使用终端实际显示的地址 |

## 10. 本课程的仿真范围

当前支持单电池的小型直流串并联与分压电路，最多 24 个元件、120 根导线，LED／二极管／蜂鸣器合计最多 6 个。电池可调 1.5–9 V、默认 4.5 V，红色 LED 压降为 2.0 V，二极管为 0.7 V。单电阻与单 LED 正向导通时按 `(电池电压 − 2.0) ÷ 电阻值` 估算（本说明中的示例使用 4.5 V）；复杂接法按实际支路求解。并联理想器件无法唯一分配电流时会提示不支持。

20 mA 是本课程的工作限制，不是所有真实 LED 的统一损坏阈值。当前不模拟器件容差、发热、击穿、损坏或真实光度；不要用相对亮度示意或这些估算判断真实器件的安全性。

页面底部「关于本课程的仿真模型」可展开查看说明。教学提示来自预设课程内容，当前没有接入生成式 AI。详细模型见 [电路模型](CIRCUIT_MODEL.md)。

## 阶段2：电子元件实验

元件盒现在包括12类元件。选择元件可先看用途、逐脚接法和常见错误；预览及旋转后的脚标对应实际孔位。固定电源可选择直流电池或实验室提供的教学方波，两模式互斥，切换后须重新运行。

1. **RGB混色**：共阴K接负端，R/G/B各经独立330Ω到正端，可各串保持开关。运行后逐通道查看电流和混色；100Ω红通道会超课程限值，可请求三级提示再自行修复。
2. **NPN开关**：E接负端；正端经330Ω、红LED到C；正端经开关及10kΩ到B；B经100kΩ到负端，C另经100kΩ到正端。断开时截止；闭合后可比较10k／100k基极电阻。虚拟脚序B/C/E不代表真实型号。
3. **RC充放电**：新建电容默认100nF；做这个观察实验时，先在容量预设中明确选100μF。无极性电容一脚接负端；另一脚经充电开关及10kΩ到正端，并经另一个10kΩ及放电开关到负端。100μF时τ=1秒。运行约5秒后先断充、再闭放，电压连续。两开关都断开为保持。改R延续电压；改C会停止，重启从0V；停止软件不是物理放电。后台暂停、返回不补算，单次最多60秒。
4. **无源压电**：选择教学方波，经开关和压电回负端，比较250／500／1000Hz。先看文字，主动启用声音才播放同频正弦示意；串1MΩ时驱动幅度不足，减小串联阻值可恢复。直流对照不持续发声。

运行后右侧显示新器件读数。普通RC更新不保存作品，刷新只恢复配置且保持停止。模型仅支持指定DC、单电容线性RC、单压电串联路径；不支持的混接保留作品并说明限制，不代表真实电路必然错误。基础测量仍暂缓。完整接线和数值见 [四实验脚本](changes/CR-STAGE-2-EXPERIMENTS.md)。本说明不表示教师／学生、真实读屏或设备试听已完成。

### 设置100nF电容

所有实验模型新放置的电容默认100nF；已有作品中的100μF等容量保持原值。选中电容可切换nF／μF显示单位，100nF=0.1μF。切换显示单位只改变显示；输入数值后点击「应用电容容量」才修改作品。

「原实验模型」支持100nF，以及10–1000μF内的完整数值；预设包括100nF、10μF、100μF、1000μF。47nF、220nF或1μF等其他值不属于这个模型的支持集合，非法或未完成输入会保留供修正，不覆盖已应用容量。「自激发声·虚拟模型v2」支持47–1000nF（0.047–1μF），预设47／100／220／1000nF；设置1μF时选择μF单位并输入1，或用1000nF预设。1000nF=1μF，默认仍为100nF；切换模型保留原容量，若不适用会提示先调整，不自动换算数值。

容量增大不保证发声：观察窗仍为40ms，可能不足以确认稳定周期。当前具名2N3904／2N3906参考接线配1μF有已知数值收敛限制，会显示“运行受限”，无有效读数或连续音；不代表真实电路一定不能工作。

100nF配10kΩ的时间常数只有1ms，当前正常速度的显示更新可能看不到短暂变化；看到快速接近稳态不代表没有计算充电。希望逐步观察充放电时，用上述100μF、10kΩ实验，时间常数为1秒。

### 使用标准SPICE晶体管模型

选择「自激发声·虚拟模型v2」，先点击板上的每只晶体管，在「晶体管参数模型」中把NPN选为2N3904、PNP选为2N3906，再勾选「标准SPICE晶体管动态模型」。作品含通用卡时，复选框暂不可勾选，并显示操作说明；标准SPICE已勾选后若改回通用卡，计算停止，需选回具名卡或取消勾选后才能运行。型号、参数和接线会保留，不自动替换通用卡。

点击运行，模型按固定27°C计算0–40ms。第一次需要加载较大的本地计算模块；没有后端或电路上传。选择会保存，也可以撤销；旧作品不会自动更换模型。

原图的`.1μF (104)`应设100nF。当前原图接线与8Ω纯电阻扬声器负载，在完整SPICE下仍得到近直流，端压约1.037V，因此没有持续声音；这不证明实物一定不振荡。型号动态更完整不等于已经模拟扬声器机械特性或真实器件安全。

想在完整型号卡下观察周期，可做一个明确改变外部参数的对照实验：把原图的120kΩ偏置电阻改为240kΩ，其余保持9V、47Ω、10Ω、100nF、8Ω负载及2N3904／2N3906完整卡。独立原生SPICE和实际Chromium应用均检测到约157.89Hz、扬声器交流RMS约0.343V；这仅验证当前计算模型的调整电路，不代表原图120kΩ也应起振或实物频率已校准。通用虚拟卡的增益／结电容是不同的模型条件，其约288Hz结果不能直接套用到型号卡。
