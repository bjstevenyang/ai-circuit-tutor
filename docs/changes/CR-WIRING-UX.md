## 范围与产品规则

### W1：曲线及可调整的控制柄

1. 新建导线默认平滑曲线；已有作品的两种折线保持原形，不自动重排。新建和所选导线的路径选项为“曲线／先横后竖／先竖后横”。
2. 选中曲线时显示一个控制柄及必要的辅助线，可拖动改变曲线走向，便于手动避开其他线。控制柄可键盘聚焦，方向键每次移动10个画布单位、Shift＋方向键移动1个单位；忽略按键重复事件，一次有效按键形成一次编辑。端点仍有独立的改接柄／表单。
3. 曲线采用单个二次贝塞尔控制点。持久字段及默认算法固定见[SYSTEM_DESIGN](../SYSTEM_DESIGN.md#cr-wiring-ux曲线与共孔设计提案2026-11-12)。允许控制点落在端点连线上，此时显示为退化直线，端点不能相同。
4. 创建、拖动预览、改接预览、选中高亮、实际线条和命中带采用同一几何函数。颜色／线形／控制点／绘制顺序均不建立或改变电气连接。
5. 控制柄拖动只预览，松手至多提交一次编辑／历史／保存；未移动不提交。Esc、pointercancel、丢失捕获、窗口失焦、无效落点均取消预览，不增加历史；工具／选择切换、目标线删除或文档版本变化也取消，不覆盖其间发生的其他编辑。不允许曲线调整被误解为端点改接或元件移动。
6. 控制点必须有限且位于规定画布范围；拖动在边界夹紧并显示实际落点，越界或缺字段的外部存档不猜测默认值。键盘到边界无可移动距离时无编辑。
7. 切换折线为曲线时创建默认控制点，切回折线移除曲线控制点；颜色修改保留当前形状。已有曲线改接只替换指定端点，保留ID、颜色、控制点及另一端。
8. 手动调整改善可读性，不承诺自动消除任意交叉／重叠；不加入自动避障、多控制点路径、导线交点或新依赖。

### W2：按操作模式确定点击优先级

1. “查看连接”模式中，导线线身的命中带优先于背景插孔；点击线身选中导线并高亮，不同时选中／触发其下方孔位。保留至少13个SVG单位的线身命中宽度。
2. 元件可见本体保持选择／拖动优先，运行中的开关与按钮本体操作不被导线命中带截获；选中导线的控制柄及两端改接柄置于交互顶层。
3. “连线”模式中，孔位／引脚命中区域优先于导线线身；元件实际插入孔必须能作为点击或拖动连线的起点／终点，不启动元件拖动。元件本体与引脚命中区域须区分。
4. 可通过现有Tab／Enter路径选中被完全重叠的导线，再调整控制点；本轮不增加对象列表或复杂的重叠轮选手势。
5. 被线身盖住的孔位仍可通过方向键／Enter或连接观察器表单查看。缩放、页面滚动后点击／拖动坐标仍对应同一画布位置。
6. 选择、聚焦、悬停只改变临时UI状态，不修改作品、历史、保存或运行结果；真正改变曲线／端点时才按现有规则停止并清旧结果。

### W3：一个元件引脚与一根导线共孔

1. 每个中央安装孔最多容纳一个元件引脚及一个导线端点，两者可以共用同一孔位ID。电源轨仍最多一个导线端点；元件仍只能安装到中央孔位；电池端口仍最多一个导线端点。
2. 元件之间禁止共孔，导线之间禁止共孔，本体重叠、越界、组件与导线总数等原限制保持。物理／虚拟安装许可与电气诊断分开，不阻止合法但错误的接线。
3. 下列入口使用相同占用规则：先放元件后接线、先接线后放元件、移动／旋转元件到有导线的孔、改接到元件引脚孔、直接载入／保存／分析。
4. 显示／可访问说明区分“空闲／仅引脚／仅导线／共用”，并与当前操作所允许的另一插入端一致；不能笼统以“已占用”将可接线的引脚孔视为完全不可用。
5. 移动／删除元件，导线仍固定原孔位；删除／改接导线不移动元件。两类占用分别释放；撤销／重做恢复各自身份和状态。
6. 同孔导线直接与该引脚相连；接到该引脚同一导电组的其他孔仍可用且电气等价。曲线经过孔位或与其他线交叉不建立连接。
7. 说明中标注这是虚拟接线的便利规则，保留实物面包板使用同组其他孔的接法；更新“引脚孔不能接线”等绝对说法，不改变实际板的分组。
8. 不扩展为多根导线或多个元件引脚共孔，不新增实物插孔容量模拟、器件、求解器、服务或公开部署。
