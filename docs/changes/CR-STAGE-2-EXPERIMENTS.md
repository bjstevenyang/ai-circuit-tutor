# 阶段 2：四个参考实验与独立验收基准

2026-11-04 需求作者规格提案，等待完整需求版本批准。教学方向已获同意，依据见 [方向决定](https://github.com/bjstevenyang/ai-circuit-tutor/pull/2#issuecomment-6624299769)。本文不是业务实现或学生试用结果；数值依据 [CIRCUIT_MODEL](../CIRCUIT_MODEL.md)，状态／保存依据 [SYSTEM_DESIGN](../SYSTEM_DESIGN.md)。

接线用电气端口／网络描述，非物理孔位 ID：`P` 为电源输出正端，`N` 为参考负端，`X/B/C` 等为实验局部网络。学生通过引脚同组空孔连接，不能把线插进已占的引脚孔。实现端到端样例必须给出通过完整物理校验的实际孔位，并从空板走非拖动路径；不把下面逻辑端口伪称为已验证安装。摆放方向、孔组替换、导线颜色／折点和对象顺序变化不改变电气期望。

四实验按 RGB→NPN→RC→压电顺序。每个实验能用元件盒、放置表单、孔位／连线表单、可见控制及键盘完成；说明可先读，不自动接线／修复。实验步骤是教程内容，不增加任务状态存储或目标图自动判题。

## E2-RGB：三色光如何组合（EX2-01/02/09/11）

- 器件：RGB×1、电阻330 Ω×3、保持开关×3；直流4.5 V。
- 网络：K→N；对 ch=R/G/B，P→S_ch→330 Ω→ch；各通道独立，三个开关初始断开。
- 操作：读四脚说明，键盘搭建并运行；依次只开 R、G、B，再开 RG、GB、RB、RGB；改变某一支路电阻为1 kΩ，观察只该通道电流／混色变化。运行中开关动作即时重算，拖动不会误切换。
- 独立期望：R=7.575757576 mA，G=B=4.545454545 mA；全开总16.666666667 mA；全开混色分量(157,122,122)。R改1 kΩ后2.5 mA、分量90，G/B不变。全断开为截止而非未计算；停止后均为未计算。
- 错误与修复：R支路电阻改100 Ω，R=25 mA，仅R通道超流，颜色封顶；改回330 Ω清故障。交换真实端点使单通道反接时有证据或明确无法归因。另用相同 Vf 的G/B并联共330 Ω形成非唯一分流，省略通道数值；恢复两只独立电阻后各4.545454545 mA。不要拿R/G不同压降样例冒充必然非唯一。
- 学生解释任务：“三个灯为什么各需要电阻？只减弱红色，会影响什么？”教师看能否指出三条实际支路，而非只记颜色按钮。

## E2-NPN：小控制路径控制负载（EX2-03/04/09/11）

- 器件：NPN×1、红LED×1、330 Ω负载电阻、10 kΩ基极电阻、100 kΩ下拉电阻、保持开关×1；直流4.5 V。
- 网络：E→N；P→330 Ω→LED.A，LED.K→C；P→S→Rb(10 kΩ)→B；B→100 kΩ→N。下拉确保开关断开时基极参考明确。
- 操作：先选中辨认B/C/E；从空板搭建，运行，断开／闭合S；在接通时将Rb改100 kΩ再改回10 kΩ。观察控制路径与负载路径，说明用基极电阻而非导线直接连电源。
- 独立期望：断开S时Ib=Ic=0，截止、LED不亮；接通且Rb=10 kΩ时VBE=.7 V、Ib=.373 mA、VCE=.2 V、Ic=6.969696970 mA、Ie=7.342696970 mA，饱和；Rb=100 kΩ时Ib=.031 mA、Ic=3.1 mA、Ie=3.131 mA、VCE=1.477 V，为本教学模型受控导通区，LED较暗。Ib扣除下拉电阻电流，不能只套单电阻公式。
- 负例：移除Rb改直连时报告无有限基极限流、无电流数值；交换C/E不自动判正常开关；移除基极参考使结果无法确定则明确不支持。修复Rb和端点后重算，诊断／三级提示证据指向实际器件／支路。
- 边界模型测试：Ic=100Ib 且VCE=.2 V两区域重合时只接受同一端电压／电流；基极增益关系、电源总电流和Ie=Ib+Ic均独立核对。所有DC数值容差按模型。
- 学生解释任务：“断开的是哪条路？负载的电来自哪里？”不要求掌握模拟放大器或真实晶体管型号。

## E2-RC：充电后怎样放电（EX2-05/06/09/10/11）

- 器件：无极性虚拟电容100 μF×1、10 kΩ电阻×2、保持开关×2；直流4.5 V，声明初态0 V。
- 网络：电容1→X，2→N；P→S_charge→R_charge(10 kΩ)→X；X→R_discharge(10 kΩ)→S_discharge→N。
- 初态：充电开关闭合，放电开关断开。运行后自动推进；参考τ=1 s。在t=0、1、5 s查看器件反馈（端到端可控时钟精确到这些点，学生观察以模拟时间为准）。
- 充电期望：Vc=0、2.844542515、4.469679239 V；Ic=.45、.165545749、.003032076 mA，正向充电；长期趋于4.5 V／0 A，稳态不误报普通断路。
- 在t=5 s先断S_charge，再闭S_discharge（同一接受模拟时刻切换的数值样例）；Vc连续，从4.469679239 V开始放电，1 s后Vc=1.644303100 V、Ic=−.164430310 mA。真实学生操作有间隔时从界面实际切换时刻／电压继续，不能强制套5 s值。两开关都断开时保持电压、Ic=0，不播放放电动画。
- 两开关同时闭合：V∞=2.25 V、Rth=5 kΩ、τ=.5 s，按当时Vc趋向2.25 V；不会自动互锁。两只开关仍为原双端开关。
- 改变R_charge为100 kΩ会使只充电路径τ=10 s；改容量为1000 μF也使τ=10 s，但改容量停止会话，下次运行从0 V开始。文本解释两种改变为什么都变慢。
- 负例：电容直接接理想源、两脚均无参考地、多电容或非线性混接，运行明确给限制，保留作品；恢复支持接法可再运行。停止清读数；再运行从0 V，刷新只恢复配置；后台暂停不补算。普通时间步保留可读提示快照，控制事件／诊断变化重置。
- 学生解释任务：“断开电池后为什么还可通过电阻放电？停止仿真是否等于完成放电？”应能指出储能状态与软件停止不同。

## E2-PIEZO：变化信号和音调（EX2-07/08/09/10/11）

- 器件：无源压电×1、保持开关×1，选实验电源“教学方波”，默认500 Hz。网络P→S→piezo.1，piezo.2→N；信号源自带1 kΩ输出电阻，非额外未列器件。
- 操作：先读“实验室提供的驱动信号”说明；从空板接线，闭合S、运行。声音默认关闭，文字显示受驱动500 Hz；主动允许声音后播放同频正弦示意，再选250／1000 Hz比较音调。切频一次编辑／历史；不加入音乐编程。
- 基准：R=1 kΩ、Rp=1 MΩ、Cp=10 nF，τp≈9.990009990 μs；500 Hz稳态Vpp≈4.495504496 V，足够驱动。250／1000 Hz读数频率分别准确对应设定，音频振荡器频率相同，不能由UI刷新采样估算。
- 串1 MΩ外电阻时Vpp≈0.224029701 V（500 Hz），不足1 V，文字说明幅度不足并停声；移除后恢复。交换两脚音调不变。断开S无驱动、短接压电为旁路，均不响。
- 切回直流电池4.5 V，先停止；重新运行同接法，只有稳态电压、Rp电流4.5 μA，无持续音，说明忽略接通瞬间。不能说“无源器件坏了”。教学方波非法频率（例如0/2000/NaN）被格式验证拒绝，原有效设定不变；不把未支持值写入作品后继续播放。
- 音频检查：关闭许可、0%音量、停止／编辑失效／退出／后台均停声；返回前台只在许可且驱动有效时恢复。API不可用保留文字反馈。设备试听由人工执行，不能从振荡器断言推断听感。
- 学生解释任务：“为什么同样接电，直流时不持续响？500到1000 Hz改变了什么？”用它与已有有源蜂鸣器对照，不要求模拟真实机械共振或声压。

## 人工教学检查与交付边界

实现自动化门槛为：四实验都从空板经合法物理安装、无拖动路径完成，并包含至少一个错误到修复的过程；每条期望独立于项目求解器计算。实际文件与命令结果按 TEST_PLAN 记录，不以本文出现数字冒充通过。

人工验证单列：1名教师审阅全部术语、模型边界和四实验；至少3名12–16岁学生在获得器件说明后依次尝试，记录能否指出实际引脚、完成接线、解释上述问题及借提示修复；所有观察逐人记录，不设“通过即证明教学有效”的结论。首次试用至少2/3能在不由成人代接线下完成各实验并口头解释核心因果，若未达到则记录障碍并修改教学内容再试。教师审阅、学生试用、读屏与200%缩放、真实设备试听均为待执行人工门槛；未执行时只能交付模型／交互自动化验证，不能宣称教学有效或完整人工验收。基础测量暂缓，器件反馈不扩成万用表工具。
