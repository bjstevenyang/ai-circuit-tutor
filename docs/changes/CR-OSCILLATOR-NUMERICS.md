## 失败、目标与选定取舍

原10/5pF、BE步加倍LTE与10ps下限组合在0.0007880928149619716s、3381接受/25拒时失败且尚无D=1V上穿；协调者独立执行同复现得到相同结果。Newton收紧不能消除10ps的LTE>1。[完整失败/早期探索](CR-OSCILLATOR-NUMERICS-IMPACT.md)保留，不删除不混为成功。原无LTE起振参考不足以证明生产契约可达。

采用唯一完成有限核验的oscillator-em-v2：每管虚拟Cbe=2nF、Cbc=1nF；EM的IS/VT/BF_N100/BF_P50/BR、原七节点/9V/外部100nF/全部电阻及8Ω虚拟负载不变。是明示的新虚拟动态模型，不是等效优化或真实3904/3906拟合。100μs单次上电、冷零态、40ms窗口、原默认/严格LTE、10ps下限、模型域和有限观察量容差保持。声音仍来自speaker端口求解，不隐藏方波/预置音/拓扑匹配/1RC猜频率。

已知v1只恢复配置/允许合法编辑保存、不允许运行；学生显式选v2是一个可撤销编辑，保留所有值/ID/接线，停止旧会话、不缩放C或静默重解释。schema仍5，旧schema v1–v4补legacy不变；未知profile/schema继续保护原文本。新建/可用模型只有legacy和v2，旧v1有可读说明和转换入口，不作为新实验选项。

为确定全窗阈值且保持≤4096显示采样，选最多两遍确定性流式分析：第一遍取全窗极值/末窗DC统计，第二遍同初态/配置重放，按固定阈值流式算上穿/最近四周期；不存全部轨迹。全部遍共享1,000,000接受/10,000拒绝/5s/取消预算，完整编译及全部分析P95≤2s目标不变；不能在第二遍重置计数/截止。内部重放不代表两次物理刺激或80ms，不提前发声。详细计数/半步及界面契约在模型/设计。
