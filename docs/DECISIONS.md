## v0.3：2026-11-01

以下条目扩展 D05／D20 的固定电压及预设阻值规则、更新 D23 的当前文档版本，并明确 D30 的运行中开关操作例外；其余历史决定保留。

| ID | 状态 | 决策及理由 |
| --- | --- | --- |
| D31 | 用户确认实施／实施约定 | 电阻支持 10 Ω–1 MΩ 自定义，电池支持 1.5–9 V，默认 4.5 V；先校验草稿再原子应用。合法但超流的设置允许实验，通过诊断反馈 |
| D32 | 实施约定 | 文档格式 3 保存电压；旧 v1／v2 固定电压作品按 4.5 V 迁移，存储键保留，加载不写回 |
| D33 | 用户确认实施／实施约定 | LED 按独立支路电流显示相对亮度，20 mA 封顶；用 sqrt 映射加强小电流变化的可见性，不作为真实光度预测 |
| D34 | 用户明确请求／实施约定 | LED 加 A＋／K−、圆／方脚标记、K 侧平边、实际孔位与可访问说明；符号不表示已接电源 |
| D35 | 用户明确请求／实施约定 | 蜂鸣器提高默认增益并提供会话内 0–100% 音量，默认 50%；0% 静音，仍主动启用；供电过压单独诊断并停止鸣响 |
| D36 | 用户明确请求 | 运行后开关本体点击／Enter／Space 可直接切换；拖动不改变通断，重复按键不连跳。纯查阅可用元件盒，更新先前只读说明的交互例外 |

本版不增加电源数量、元件类别、外部服务或依赖；继续仅执行 Chromium 浏览器验证，不公开部署。
