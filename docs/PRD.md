# AI Circuit Tutor：MVP 产品需求

日期：2026-10-30。状态：用户已批准本方案实施。技术与电气约定分别见 SYSTEM_DESIGN 和 CIRCUIT_MODEL。

## 1. 用户与目标

服务 12–16 岁的电路初学者，帮助理解面包板内部连接、准确安装与布线，并通过逐级提示自行修复错误。

第一课完成“搭建 → 查看连接 → 运行 → 理解诊断 → 请求提示 → 修改 → 再验证”的完整学习闭环。改善初学体验是待学生试用验证的目标，不宣称已证明优于其他产品。

## 2. MVP 行为

- 学生可自由放置、移动、旋转、删除一个电阻和一颗红色 LED；工作台提供固定外置电池。
- 放置显示全部引脚预览并吸附到孔位，拒绝越界、占用和元件本体重叠。物理可放置的电气错误允许存在。
- 导线连接明确端点，可选择颜色和两种折线路径；交叉不连接。
- 点击孔位或使用孔位输入，查看通过内部导体和导线直接相连的孔／端口。
- 手动运行，显示受支持结果、电路问题或模型不支持；不编造未知接法的数值。
- 诊断关联可见对象。提示仅按请求推进三层：概念、相关区域、具体修复；系统不自动修复。
- 修改后旧结果及提示失效。课程完成按电气行为判断，不匹配参考布局。
- 支持最近 50 次已完成编辑的撤销／重做；重置可撤销。
- 单工作区在浏览器本地自动保存并恢复；失败有反馈且保留内存作品；无法读取的存档不自动覆盖。
- 桌面 Chrome、Edge、Firefox 和 Safari，支持鼠标／触控板与键盘。提供不依赖拖动的完整路径。

## 3. 验收标准

| ID | 可观察结果 |
| --- | --- |
| AC-01 | 孔位内部连接、中央沟槽和四条独立连续电源轨与批准的板定义一致；连接观察器显示实际导电网络 |
| AC-02 | 电阻、LED 可放置、移动、旋转和删除；预览准确，非法物理操作原子拒绝，电气错误可以搭建 |
| AC-03 | 导线仅连接显式端点；交叉、颜色和折线路径不改变电气连接；占用孔位不能再次插入 |
| AC-04 | 正向串联回路默认电流约 7.58 mA；电阻在 LED 两侧均被接受；100 Ω 对应约 25 mA 并提示超限 |
| AC-05 | 短路、缺少／旁路电阻、LED 旁路、断路和已识别回路中的 LED 反向有准确诊断；不支持接法不获得虚构结果 |
| AC-06 | 每次请求只揭开一层提示；前两层不直接给修复；第三层允许具体修复；编辑后清除旧结果和提示 |
| AC-07 | 撤销／重做还原已完成编辑，最多 50 步；重置可撤销；每次操作只产生一条历史 |
| AC-08 | 刷新恢复成功保存的作品；写入失败保留内存文档并提示；损坏／未知格式存档不自动覆盖 |
| AC-09 | 学生无需拖动即可完成放置、布线、检查、运行、提示与修复；焦点可见，诊断不只靠颜色 |
| AC-10 | 模型参数、近似和限制可查看；成功仅表示满足课程模型，未声称真实器件安全或教学效果已验证 |

## 4. 完成与非目标

课程完成需要一个电阻与正向 LED 形成受支持串联回路，估算电流大于零且不超过 20 mA。接受电气等价布局、同组孔位替换和电阻位于任一侧。

当前不包括：任意电路求解、多个负载／电源、交流、瞬态、Arduino、损坏模拟、多课程平台、账户、教师后台、评分、云同步、文件分享、移动端编辑、实时 AI 和公开托管。

学生试用应观察能否解释连接、独立修复，以及提示是否过早或不足；不得以功能和测试完成替代学习效果验证。
