# 电路模型与电气约定

日期：2026-10-30。以下为用户已批准的首课教学模型，不是通用 SPICE 或真实器件安全预测。

## 1. 固定面包板

boardId：`breadboard-30-v1`。横向绘制 30 个编号列，编号代表通常竖向板的行；电气含义不随绘制方向变化。

| 孔位 ID | 坐标 | 内部导电组 |
| --- | --- | --- |
| aN、bN、cN、dN、eN | x=140+20×(N−1)，y=170、190、210、230、250 | 每个 N 的 a–e 一组 |
| fN、gN、hN、iN、jN | 同上 x，y=310、330、350、370、390 | 每个 N 的 f–j 另一组 |
| top+:N | 同上 x，y=100 | 全部 30 孔连续 |
| top-:N | 同上 x，y=120 | 全部 30 孔连续 |
| bottom+:N | 同上 x，y=440 | 全部 30 孔连续 |
| bottom-:N | 同上 x，y=460 | 全部 30 孔连续 |

N 为 1–30。不同编号五孔组、中央沟槽两侧、四条电源轨之间以及电源轨与中央孔位均不内部连接。加减标签不赋予电压。真实面包板可能存在分段电源轨，当前只代表这一明确型号的虚拟结构。[Adafruit 连接及分段电源轨说明](https://learn.adafruit.com/breadboards-for-beginners/breadboard-tips-and-tricks)

## 2. 元件与安装

- 固定理想电池 4.5 V，端点 `battery:+`／`battery:-`，坐标 (285,565)／(325,565)。不模拟内阻或耗电。
- 一个电阻，可选 100、330、1,000 Ω，默认 330 Ω。两引脚间距 60 绘图单位，即三个孔距。
- 一个红色 LED，A 为第一引脚，K 为第二引脚。两引脚间距 20，即一个孔距。
- 安装锚点为第一引脚的 a–j 孔位；旋转 0° 向右、90° 向下、180° 向左、270° 向上。第二引脚必须落在有效中央孔位；不允许任意拉伸引脚。
- 所有孔和电池端口最多一个插入端。安装本体区域不得重叠，导线从元件上方经过不算碰撞。

两只引脚插在同一导电组是可教学的接线错误，物理校验允许。电阻先后顺序与引脚互换不改变电气行为。

## 3. 导电网络

以明确孔位 ID 和端点构造图，合并内部导电组及理想导线连接，得到直接导通网络。电阻、LED 和电池保持为网络之间的支路，不合并器件两端。

导线交叉、折点、经过其他孔位、靠近元件、颜色和渲染顺序均不建立连接。冗余导线不改变网络；删除桥接导线后必须重新计算网络。

## 4. 数值与完成条件

仅对已识别的单电池、单电阻、单 LED 串联回路进行数值分析。电阻可位于 LED 任一侧，不按参考图片或具体孔位判定。

LED 正向压降固定为 2.0 V。正向时：`I=(4.5−2.0)/R`。

| 电阻 | 估算电流 | 课程结果 |
| --- | --- | --- |
| 100 Ω | 25 mA | 超过课程限制 |
| 330 Ω | 7.575757… mA | 完成 |
| 1,000 Ω | 2.5 mA | 完成 |

课程限制为 20 mA，完成条件为完整正向串联且 0<I≤20 mA。反向 LED 在已识别完整回路中电流为零、不亮；忽略泄漏和击穿。

真实 LED 的正向压降、额定电流和温度特性因型号与工作条件而异；本模型的 2.0 V 和 20 mA 不构成通用器件常数。[Kingbright WP7113ID 数据表](https://www.kingbrightusa.com/images/catalog/SPEC/WP7113ID.pdf)

## 5. 诊断与支持范围

| 代码 | 可证明的条件／含义 |
| --- | --- |
| source-short | 理想电池正负端属于同一直接导通网络，优先报告；无有限电流估算 |
| missing-resistor | 缺少课程所需电阻；不得将 LED 直接跨电源的电流猜为有限值 |
| resistor-bypassed | 电阻两端同网，未起串联限流作用 |
| led-bypassed | LED 两端同网 |
| missing-led | 缺少课程所需 LED |
| open-circuit | 支持范围内未形成完整串联回路 |
| reversed-led | 已识别完整串联结构，LED 极性反向 |
| overcurrent | 支持的正向回路估算电流超过 20 mA |
| unsupported | 元件数量或拓扑超出定义；不返回虚构数值和完成结论 |

多个问题顺序固定，电源短路及限流问题优先。断开回路时不能仅凭视觉推断 LED 反向。诊断携带支撑结论的元件／端点引用；不强行指定唯一“缺少哪根线”。

不模拟电容、电感、交流、瞬态、指数二极管曲线、温度、容差、真实亮度、耗电或损坏记忆。短路不显示无穷大电流，超出范围不伪装成“安全”或“断路”。
